## A little about me

I like working on problems I can see up close: finding a returning buyer's shipping details, getting photos into someone's hands at an event, or connecting a machine learning model to a usable app.

My work spans interface design, web and mobile development, and backend integration. I enjoy taking an idea from a Figma layout to a working application, with attention to the small interactions that make it easier to use.

## Selected work

### 01 / District Wheels Dispatch Directory

**A practical tool for my own business.** A searchable buyer directory for finding and reusing shipping details when repeat orders come in. I designed, developed, and integrated the app end to end, and use it to manage fulfillment.

`React` `JavaScript` `Node.js` `Express` `PostgreSQL`

[Explore the repository →](https://github.com/H1R0000/District-Wheels-Dispatch-Directory)

### 02 / Piksie Photobooth

**From camera capture to a photo you can take home.** A photobooth app with photo customization and QR downloads, used at flea markets. I built and integrated the complete app from supplied UI references.

`App development` `UI implementation` `System integration`

[Visit Piksie →](https://piksie.vercel.app/)

### 03 / Metal Screw Defect Detection

**Exploring how computer vision fits into a complete application.** An academic prototype connecting a TensorFlow/Keras classification model, a FastAPI backend, and a Flutter app for captured or uploaded images. I led development and integrated the training pipeline, API, and mobile experience. The model remains experimental and needs further validation.

`Python` `TensorFlow / Keras` `FastAPI` `Flutter` `Dart`

[Explore the repository →](https://github.com/H1R0000/AI-Powered-Metal-Screw-Defect-Detection)

### 04 / Agila Attendance System

**Testing software for field operations.** A team thesis project combining facial recognition and GPS checks for logistics attendance. My contribution focused on testing core flows, tracking bugs, coordinating beta testing, and co-authoring the thesis, including the literature review, methodology, and test results.

`Functional testing` `Beta testing` `Technical writing`
