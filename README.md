## About me

I build web and mobile applications that solve problems I encounter firsthand—from managing repeat orders for my business to helping people capture and share photos at events.

My work spans interface design, frontend development, backend integration, and applied AI. I enjoy connecting the pieces: turning a Figma layout into a working interface, connecting an API to a mobile app, and refining the details through testing.

## Selected work

### 01 / District Wheels Dispatch Directory

A searchable buyer directory for finding and reusing shipping details when repeat orders come in. I designed, developed, and integrated the app end to end, and use it to manage fulfillment for my business.

`React` `JavaScript` `Node.js` `Express` `PostgreSQL`

[View repository →](https://github.com/H1R0000/District-Wheels-Dispatch-Directory)

### 02 / Piksie Photobooth

A photobooth app that takes users from camera capture to photo customization and QR downloads. I built and integrated the complete application from supplied UI references. It is used at flea markets.

`App development` `UI implementation` `System integration`

[Visit Piksie →](https://piksie.vercel.app/)

### 03 / Metal Screw Defect Detection

An academic computer vision prototype connecting a classification model, an API, and a mobile app for captured or uploaded images. I led development and integrated the training pipeline, backend, and mobile experience. The model remains experimental and needs further validation.

`Python` `TensorFlow / Keras` `FastAPI` `Flutter` `Dart`

[View repository →](https://github.com/H1R0000/AI-Powered-Metal-Screw-Defect-Detection)

### 04 / Agila Attendance System

A team thesis project combining facial recognition and GPS checks for logistics attendance. My contributions focused on testing core flows, tracking bugs, coordinating beta testing, and co-authoring the thesis.

`Functional testing` `Beta testing` `Technical writing`
